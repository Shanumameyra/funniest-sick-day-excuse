## The line

> Sorry, I can't come in today — I woke up only able to turn my head left, so driving to work would be a series of very confident wrong turns.

## How it works

`main.py` is a deterministic, offline program (standard library only). It writes
exactly that one line to the harness output path (`$MAKEFUN_OUTPUT_DIR/entry.txt`,
default `/output/entry.txt`). The line is 140 characters (142 bytes of text,
143 bytes with the trailing newline), inside the 1–200 character gate.

## Why this line

It is a reason a boss might half believe — a stiff neck — that a coworker would
laugh at, with the twist landing on the very last words ("very confident wrong
turns"). The idea is fresh (no fever, no dog, no dead grandmother), it reads as
a real person typing a text message, and every clause is doing work.
